# مهامي | My Tasks

تطبيق جوال لإدارة المهام اليومية والشخصية والعملية، بالعربية بالكامل ومن اليمين إلى اليسار، يعمل على Android وiOS (والويب للتجربة).
مبني بـ **Expo SDK 58 + React Native + TypeScript**، وقاعدة بيانات **SQLite** حقيقية على الجهاز.

## التشغيل

```bash
npm install
npx expo start          # ثم امسح رمز QR بتطبيق Expo Go أو شغّل على المحاكي
npx expo start --web    # تجربة سريعة في المتصفح
```

لبناء نسخة قابلة للتثبيت (APK / iOS):

```bash
npx eas-cli@latest build --platform android --profile preview
npx eas-cli@latest build --platform ios
```

> ملاحظة: اتجاه RTL مفروض عبر إعداد `expo-localization` (`forcesRTL`)، ويظهر بالكامل في نسخة البناء (development / production build). في Expo Go يتبع اتجاه لغة الجهاز.

## الشاشات

| الشاشة | المحتوى |
|---|---|
| **اليوم** | التاريخ واليوم، المطلوبة / المنجزة / المتبقية، نسبة الإنجاز، إضافة سريعة بسطر واحد، المهام المرحّلة، مهام اليوم |
| **القادمة** | المهام المستقبلية مجمّعة حسب اليوم أو الأسبوع أو الشهر + قسم المتأخرة |
| **التقويم** | شبكة شهرية (تبدأ السبت) بعلامات للمجدولة والمتأخرة والمنجزة والتكرار المتوقع، وإضافة مهمة ليوم محدد |
| **الأرشيف** | كل المهام المنجزة مع تاريخ ووقت الإنجاز، بحث (يتجاهل الهمزات والتاء المربوطة)، تصفية بالتصنيف، استعادة |
| **الإحصائيات** | يومي / أسبوعي / شهري: نسبة الإنجاز، المتأخرة، الإنجاز في الموعد، الأيام المتتالية، رسم يومي، حسب التصنيف |
| **الإعدادات** | الوضع الليلي/النهاري، ترحيل المهام، التنبيهات، التصنيفات، سلة المحذوفات، النسخ الاحتياطي |

## قواعد العمل المطبّقة

1. المهمة الجديدة تظهر في «اليوم» أو «القادمة» حسب تاريخها.
2. علامة ✓ تسجّل وقت الإنجاز وتنقل المهمة للأرشيف فوراً (مع زر «تراجع»).
3. المهام غير المنجزة لا تُحذف تلقائياً أبداً.
4. المهمة التي فات موعدها (التاريخ، أو الوقت إن وُجد) تظهر باللون الأحمر كمتأخرة.
5. التأجيل/النقل يحافظ على كل بيانات المهمة ويحفظ تاريخها الأصلي وعدد مرات التأجيل.
6. الحذف ينقل المهمة إلى «سلة المحذوفات»، والحذف النهائي يتطلب تأكيداً صريحاً.
7. يمكن استعادة أي مهمة من الأرشيف أو من السلة.
8. **ترحيل المهام غير المنجزة**: تظهر المهام المتبقية من الأيام السابقة تلقائياً أعلى قائمة اليوم مع تاريخها الأصلي (قابل للإيقاف من الإعدادات).

إضافات: المهام المتكررة (يومي/أسبوعي/شهري) تُنشئ الموعد التالي تلقائياً عند الإنجاز، وسجل تعديلات لكل مهمة.

## التنبيهات

- تذكيرات متعددة لكل مهمة (عند الموعد، قبل 5/15/30 دقيقة، ساعة، ساعتين، يوم).
- المهام بدون وقت تُذكَّر على ساعة افتراضية من الإعدادات.
- ملخص صباحي يومي، وتنبيه مسائي بالمهام غير المنجزة.
- يُعاد حساب جدول الإشعارات من قاعدة البيانات بعد كل تعديل، فلا تبقى تنبيهات لمهام منجزة أو محذوفة.

## الحفظ والنسخ الاحتياطي والمزامنة

- كل البيانات في SQLite على الجهاز (`mytasks.db`): المهام، التصنيفات، سجل التعديلات، الإعدادات.
- نسخة احتياطية تلقائية يومية على الجهاز (آخر 7 أيام) قابلة للاستعادة.
- تصدير ملف JSON ومشاركته (Google Drive / iCloud / بريد)، واستيراده على جهاز آخر.
- الاستيراد **يدمج** ولا يحذف: تُطابق السجلات بالمعرّف وتُعتمد النسخة الأحدث تعديلاً، فتتزامن الأجهزة دون فقدان بيانات.
- المزامنة السحابية الفورية عبر حساب مستخدم تحتاج خادماً (مثل Supabase أو Firebase) وهي غير مضمّنة في هذه النسخة؛ طبقة `Repository` معزولة لتسهيل إضافتها.

## البنية

```
src/
  app/                 الشاشات (Expo Router)
    (tabs)/            اليوم، القادمة، التقويم، الأرشيف، الإحصائيات
    task/new.tsx       إضافة مهمة
    task/[id].tsx      تعديل + سجل التعديلات
    settings.tsx, categories.tsx, trash.tsx
  domain/              منطق العمل (دوال نقية ومختبرة): التواريخ، القواعد، الإحصائيات، خطة الإشعارات
  db/repository.ts     طبقة قاعدة البيانات (SQLite) والنسخ الاحتياطي
  services/            الإشعارات والنسخ الاحتياطي
  state/store.tsx      حالة التطبيق والسمة
  components/          مكونات الواجهة
```
